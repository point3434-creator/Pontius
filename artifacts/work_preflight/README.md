`legal_river_quotient_cuda_compensated_work_preflight_v1.jsonl` in this
directory for the separately source-sealed, one-shot 10/22-card
work-decomposed capacity preflight. The path remains absent at
preregistration. It can retain only the first calibration/capacity terminal
and cannot contain a complete 25-card numerical value, an actual 45-card

keeps the repository-root artifact marker and attributes file byte-identical
to the historical authorities that hash-bind them.
