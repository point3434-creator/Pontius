## Defect-family retirement

The defect is a semantic predicate hidden inside a numerically plausible
Boolean expression: the same recurring family as tolerance-knob reuse and
stack-as-payoff-span, but in schema plumbing. The structural control walks the
AST of every `src/pontius` module and rejects any chained comparison containing
a mapping or set literal. The consumed ADR-0361 source is the sole named
tombstone. A future recurrence therefore fails the ordinary test suite even if
the expression happens to emit a Boolean.

Adversarial controls rehash mutations rather than relying on outer-byte
failure alone. Non-source factor selection, epigraph residual, compact-piece,
row-growth cap, emission, recorded gate, coordinate, duplicate-key, and outer-
byte mutations all fail closed. A timing-only row-growth mutation leaves the
semantic digest unchanged; a cap mutation changes it.
