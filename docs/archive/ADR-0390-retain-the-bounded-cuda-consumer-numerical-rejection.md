## Decision

No. Retain the additive implementation and its controls as a bounded numerical
rejection, refuse the actual-owner source seal, and leave the reserved result
absent. This is a clean scientific failure of one frozen conjunct, not an
infrastructure failure and not evidence against the occupied-card quotient
architecture.

## Engineering findings before the terminal

The bounded controls found and retired two real implementation defects before
the final rejection:

1. The first parallel in-place reduction let one CUDA block overwrite entries
   another block had not read. Default and alternate chunks exposed a material
   transpose error and repeat failure. The repair is a deterministic one-thread
   pair tree per chunk, not a scheduling assumption.
2. Correct per-chunk trees still made scalar bits depend on outer chunk cuts.
   The repair is one global online binary pair tree in increasing record order.
   Its carry occupies already-owned dead workspace: unused source levels during
   forward and consumed covector storage during adjoint. It adds no numeric
   allocation, preserves the two result slots, and makes default/alternate
   scalar and row bytes identical.

Local compensated additions and products, offset-aware kernels, the global
tree, and a fused source contraction that reconstructs one thread-local
coefficient row all survive the exact and direct controls. They do not retire
the last one-ULP operator-rounding residual. Exact binary-rational summation of
the captured Float64 contribution rows also lands on adjacent representable
values, so a scalar reducer alone is not a structural repair; the arithmetic
inside the linear operator needs a successor.

## Successor hypothesis

Preregister a same-memory compensated-tile experiment before changing CUDA
source. The primary candidate reinterprets the physical width 128 as no more
than 64 logical high/low feature pairs, processing global feature tiles in a
frozen order. It must retain exact source/query offsets, complete six-label
groups, reach ownership, normalize-once semantics, global chunk-independent
pair trees, named lifetimes, and the actual 12-GB numeric cap. Exact
binary-rational row-sum reconstruction remains an independent diagnostic, not
the deciding implementation.

Kill the candidate if either complete bounded population misses any original
absolute or relative ceiling, if default and alternate chunks differ by one
byte, if high/low tiling changes a direct row or global feature identity, if
the modeled actual peak exceeds 12 GB or its reserve, if projected laboratory
work cannot fit the existing 600,000-ms boundary, or if it requires a 45-card
value to choose the mechanism. A later protocol may choose a different
measurement only by explicitly superseding ADR-0389; it may not call the
rejected gate passed.
