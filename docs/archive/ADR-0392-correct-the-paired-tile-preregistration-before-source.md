## Paired recurrence division

The only allowed divisors are the exact positive Float64 integers 1 through 6.
For input pair `a` and divisor `d`, the sequence is frozen:

```text
q1 = a.high / d
r1 = a - TwoProduct(q1, d)
q2 = r1.high / d
r2 = r1 - TwoProduct(q2, d)
q3 = (r2.high + r2.low) / d
q  = PairAdd(PairAdd((q1, 0), (q2, 0)), (q3, 0))
```

Every zeta cell adds child pairs in increasing card order, then applies this
primitive with `source_cards - level`. Reciprocal multiplication and a
high-only remainder are forbidden alternatives. The primitive suite covers
all six divisors, zero and nonzero lows, cancellation remainders, and observed
recurrence exponent extremes against an independent `Fraction` reference.

## Source and query factor order

Each source-pairing weight starts at `(1, 0)`. Seats 0, 1, and 2 are processed
in order; for each seat, unary weight then mode factor is applied by successive
pair-times-Float64 operations. Pre-multiplying unary and mode as one Float64
is forbidden.

Each query weight starts at `(mixture_weight, 0)`. Seats 3, 4, and 5 are
processed in order with the same unary-then-mode sequence. The paired weight
is multiplied by one Float64 payoff to form a paired query covector. The old
parent's Float64 query-weight helper is not a permissible successor path.
Controls must show nonzero low-lane query mass and reject factor-order,
pre-product, and parent-helper mutations.

Fold and source-adjoint contraction both use pair-times-pair, followed by pair
addition in increasing global-feature order. This makes the forward and
transpose arithmetic choices explicit at the seam where ADR-0390 differed.

Tile numerator pairs combine in canonical tile order 0, 1, 2. Tile 2 alone

Fraction.from_float(low)` values. Conditional chip value is the exact numerator
fraction divided by the exact positive reach fraction. Its collapsed Float64
