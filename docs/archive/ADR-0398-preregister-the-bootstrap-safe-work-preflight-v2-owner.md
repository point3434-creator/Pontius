## Kill criteria

Kill v2 if it edits, imports, or invokes the v1 runner; changes or replaces the
v1 artifact; reuses any v1 lifecycle identity; derives the module from
`__name__`; lets mocked or injected execution stand in for the real handshake;
uses different process/framing/drain/deadline/return code for handshake and
campaign; omits the fresh challenge; loads CuPy or science during handshake;
starts campaign before a journaled handshake pass; changes any arithmetic,
population, phase, ratio, resource, wall, stop, or claim; opens population 25
numerically; or promotes infrastructure evidence into capacity, latency,
quality, truncation, blueprint, or strength evidence.
