## Why occurrence is authoritative

“Rewrite changes the hash” is equivalent to “at least one trigger exists” only
when the mutation implementation itself is correct and the target identity is
already bound. ADR-0437 therefore freezes both sides independently: count the
four literal token bytes in raw input before mutation, then require the
mutation to change bytes and digest exactly on the token-bearing set. A
token-free synthetic target terminates `unarmed_literal_escape_mutation`; it
cannot be reported as a passing rejecting control.

The standing scan also prevents the opposite post-hoc maneuver. No parent may
be edited to introduce a token merely to arm a control or to satisfy metadata.
Token-free bound parents remain expected zero-count rows whose mutation digest
equals their canonical digest. The set, counts, and digests are all fixed
before the new source exists.

## Independent correct implementations

The production normalizer replaces only adjacent byte values 13 and 10 with
one byte value 10. The independent normalizer is a forward state machine over
raw bytes. It may not call the production helper, use any `replace` method,
wrap the production result, or copy its replacement expression. Both must
emit identical normalized bytes, not merely equal digests, before SHA-256 is
compared. AST controls reject wrapper and replace-based impostors.

This is load-bearing for the new files' own seal. Their canonical digests and
forbidden mutation digests will be recorded externally in the later source-
seal ADR, together with exact one/one occurrence counts. Neither file embeds
its own digest, avoiding a self-reference masquerading as provenance.
