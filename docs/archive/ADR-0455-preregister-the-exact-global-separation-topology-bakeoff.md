## The base-producer audit precedes the bake-off

The audit has four typed terminals and may classify only from source identity,
algebra, and provenance—not by fitting observed values or noticing empirical
sparsity.

1. **Lattice-decomposable.** The producer is an objective-side disjoint-sum or
   another exact truncated-subset transform. It must expose its exact rank
   inputs, coefficients, common scale, source identity, and refresh epoch. A
   direct exhaustive reduced differential must prove that base-family seeds
   reproduce every `b(S)` before those seeds may enter the shared circuit.
2. **Genuinely opaque.** The producer supplies per-source free values or an
   equivalent object with no proved transform. Every source base must then be
   read, or covered by a separately proved conservative bound, and that work
   is mandatory.
3. **Lattice plus sparse correction.** The base must be represented as an
   exact structural lattice value plus `delta(S)`. The nonzero correction
   support must equal a source- and epoch-bound master support exactly, with
   zero correction outside it. It may not be rounded to the opaque case merely
   because one component is arbitrary, nor rounded to the lattice case by
   dropping the patch. The topology charges the circuit plus the complete
   sparse support.
4. **Producer absent.** No production classification, target benchmark, or
   topology selection is possible. The terminal is
   `base_producer_unavailable_no_bakeoff_selection`.

Embedding never erases type. H-family seeds, structural-base seeds, and any
sparse correction retain separate semantic digests and refresh epochs even
when additions share one circuit. A base refresh invalidates its seeds, patch,
and base bounds but not a still-current H contraction; an H/pricing refresh
has the symmetric rule. Preparation-bank reuse requires an exact epoch hit.

The audit also owns the first production-base numerical admission. It must
freeze the inclusive component-exponent window, semantic bound, mathematical
width, guard-inclusive width, and refresh cadence before target arithmetic.
Synthetic ADR-0453 base families cannot size production limbs.

## Four frozen arms

1. **Contract-first direct 57 scan.** Contract H rows once, visit every source
   in increasing colex order, and sum exactly 57 subset scalars. An opaque base
   adds one streamed source read; a decomposable base uses its proved circuit
   representation; a mixed base uses the structural result plus the exact
   sparse patch. This is the exhaustive scalar baseline, not the historical
   feature-wise sweep.
2. **Rank-truncated zeta closure.** Seed ranks zero through four and propagate
   along the Boolean-lattice cover edges through rank six. Stream rank-six
   prices and the complete sign/argmax reduction; do not materialize a dense
   output merely because coverage is global.
3. **ADR-0454 prefix branch-and-bound.** Use its source-sealed conservative
   bound and exact best-first traversal without post-seal tightening. Correct
   no-prune remains a valid, fully charged outcome.
4. **Frozen prefix-to-zeta hybrid.** Start with the identical ADR-0454 prefix
   traversal. Switch at most once under the count rule below, charge all work
   already spent, then run complete zeta closure. A switch does not declare
   the unvisited prefix domain covered.

All four must agree with the direct unbounded-integer authority on every
price, positive set, maximum, and full tie set whenever that output is
requested. A positive-witness call and a prove-none closure are different
output contracts and different runtime distributions.

## Exact rank-truncated circuit

Use output scale 24 and rank seeds

`w = (1, -24, 360, -2880, 8640)`.

For each level `l` from zero through four,

`w[l] * (6-l)! = 24 * c[l]`.

Define

`A_r(S) = seed_r(S) + sum_{x in S} A_(r-1)(S without x)`.

H-family seeds are zero at ranks five and six. A rank-`l` seed reaches a
six-set through exactly `(6-l)!` paths, so `A_6(S) / 24` is exactly the signed
57-subset contraction. Division must be exact when an unscaled value is
materialized; an equivalent common-scaled comparison may avoid it. The
transpose is the same cover graph reversed and must match the direct adjoint.

At 45 cards the six cover levels contain respectively
`45, 1,980, 42,570, 595,980, 6,108,795, 48,870,360` edges, totaling
`55,619,730`. The contract-first scan contains `464,268,420` subset
incidences. This is an exact 8.347-fold incidence-count reduction, not a wall
prediction. Ranks zero through five contain `1,385,980` nodes and all ranks
through six contain `9,531,040`; rank six may stream.

If a structural base enters the circuit, its producer derives its own exact
seed weights and any common-scale reconciliation. Numerical similarity to the
H weights is not authority. Separate provenance, shared circuit.

## The hybrid trigger is not adaptive freedom

Let `N = C(n,6)`. Proposal mode may terminate immediately on one exact positive
witness. Otherwise the hybrid evaluates the prefix arm until the first of two
fixed checkpoints:

- At `ceil(N/64)` exact leaves, continue the prefix only if at least
  `ceil(N/2)` sources are already certified nonpositive by exact leaves or
  conservative nonpositive blocks. If coverage is smaller, switch.
- At `ceil(N/8)` exact leaves, switch if global closure has not completed,
  regardless of reported coverage.

There is no second switch and no timing, frontier shape, family label, or
post-outcome judgment may change those fractions. Boundary-minus-one, exact,
and plus-one controls must exercise both rules. The hybrid ledger retains all
prefix work and all subsequent complete zeta work.

## Width, work, and timing contracts

Each zeta rank receives its own derived bound, mathematical limb count, and
guard-inclusive allocation. For the H-only circuit a conservative rank-`r`
bound is

`sum_l C(r,l) * (r-l)! * abs(w[l]) * H_max[l]`

over `0 <= l <= min(4,r)`. Structural-base seeds, sparse corrections, output
addition, and reductions have separate bounds. No table, neighboring rank,
or final scalar may lend its width to another semantic quantity. Memory
admission uses simultaneous lifetimes and these per-level widths.

The ledger separates H contraction, base refresh, structural-seed build,
sparse-patch build, prepared-artifact validation, subset reads, cover edges,
rank barriers, prefix bounds, exact leaves, frontier occupancy, base reads,
patch lookups, and terminal reductions. Heterogeneous counts are never added
into pseudo-time.

A later compiled timing gate must use the prospectively named card domains
`10, 12, 16, 20, 24`, one warmup, and five retained measured repeats for every
arm, runtime mode, base mode, and eligible arithmetic schedule. It reports all
five walls, median, and maximum. Its target projection must estimate and retain
an intercept plus nonnegative work slope; origin-through-zero scaling is
forbidden. The exact fit rule itself must be source-sealed before any timing
value. Positional and batched-five-then-four RRNS remain separate schedules;
no average or post-outcome weighting may choose between them.

The speed hypothesis for the zeta lane is explicit: in prove-none mode, under
the same base mode, arithmetic schedule, and common-work accounting, its total
wall is at most half the contract-first direct wall. Failure rejects that
material-speed claim, not the exact algebra.

Positive-witness, prove-none, and exact-argmax/tie work remain separate. Cold
base refresh and exact prepared-artifact hits also remain separate. No blend
is authoritative until a real consumer freezes its frequency before values.

## Kill criteria and claims boundary

if mixed provenance is rounded to opaque or lattice-only; if shared additions
erase base or H epoch identity; if a synthetic base window sizes production;

called per action while certificate frequency is null.
