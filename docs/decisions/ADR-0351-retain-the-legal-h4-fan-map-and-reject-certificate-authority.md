## Defect mechanism and structural repair

The v1 helper computed a source margin, counted `margin == 0`, then skipped the
breakpoint whenever `closing_slope <= 0`. A parallel or separating exact tie
therefore left the default scale at one. The gate subsequently checked only
that deterministic legal-order tape identity did not change below that scale.
Because exact tie breaking returned the same tape, a numerical coincidence
masqueraded as semantic uniqueness.

The structural repair changes the order of authority:

1. require every source margin to be strictly greater than its separately
   typed semantic reserve;
2. return zero immediately for a tie or reserve-overlapping margin; and
3. inspect closing slope only after source separation is established.

Five v2 controls cover parallel ties, separating ties, positive margins inside
the reserve, ordinary closing breakpoints, and genuinely nonmaximal source
actions. This retires the tie/slope coincidence family for the replacement
primitive. The old helper is not edited because its hash is part of the
closed invocation's provenance.
