## Exact logical-work result

For the 176-column fixture, one cold forward pass—or one topology-stable
source-seat refresh—has these largest counts:

```text
source labeled pairing visits                    733,055,400
state-plus-reach weighted accumulations         1,466,110,800
source coefficient zero writes                  1,433,530,560
containment vector updates                        464,268,420
containment scalar additions                   81,711,241,920
signed query vector terms                          14,303,520
signed query scalar additions                   2,517,419,520
query payoff-state folds                          156,444,750
```

A query-only unary refresh reuses source marginals and performs none of the
source or containment work. A source-seat change is not incremental: its
coefficient and containment work is exactly the cold arithmetic above.

The exact adjoint separately requires 157,338,720 labeled-query aggregation
additions, 419,569,920 four-card containment additions,
81,711,241,920 six-card signed additions, and up to 129,017,750,400 streamed
source-label scalar writes when literal record-level expansion is requested.
These are logical operations, not measured GPU instructions or milliseconds.

The memory verdict is therefore favorable and the throughput verdict remains
open. In particular, 81.711 billion irregular containment additions per source
refresh are the binding risk. No statement in this ADR says that an RTX 5080
can perform them within 14 seconds. A future GPU keystone must test the direct
kernel, numerical envelopes, work counters, and refresh behavior rather than
use peak bytes as a speed prior.

## Claims boundary

ADR-0370 establishes a complete source-level numeric-array proposal and exact
logical-work bill for the frozen river fixture plus a safe feature-width
envelope. It spot-checks combination-rank implementation rather than proving
all 8,145,060 full-width ranks by enumeration. It does not establish GPU source,
live memory, numerical accuracy, bandwidth, warm latency, a CFR iteration,
solve, complete 15-second action, decision quality, support truncation, or poker
strength. The 90-fold state quotient is real; a 90-fold speedup is not claimed.
